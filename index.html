Panduan Penggunaan

1. Alat ini untuk apa?

Membuat file Meal Number Check List yang sudah terisi otomatis dari file Meal Charge. Tidak perlu menyalin angka satu per satu.

2. Yang perlu disiapkan

  • Browser modern (Chrome, Edge, Firefox, Safari).
  • File acuan Meal Charge (.xlsx) - boleh tetap terbuka saat generate.
  • File acuan tidak akan diubah oleh alat ini.

3. Cara memakai (3 langkah)

  1. Klik area upload atau seret file acuan ke sini. Pilih file Meal Charge (.xlsx).
  2. Pilih tanggal penerbangan dari dropdown (tanggal bertuliskan "(kosong)" artinya belum ada datanya).
  3. Klik Generate & Download lalu simpan file hasilnya.

4. Nama file hasil

v2 Meal Number Check List JX 2026D - [tanggal terbang] - [waktu bikin].xlsx

Karena ada waktu pembuatannya, file lama tidak akan tertimpa. Lokasi simpan bebas diubah saat download.

5. Isi file hasil

  • Tanggal, jumlah penumpang (J/Y), dan jumlah kru (FC/CC) terisi otomatis.
  • Jumlah tiap menu (kolom NRML dan IEML) terisi otomatis dari file acuan.
  • Rincian makanan khusus (SPML) ditulis di bagian kru (JC/FC/CC/YC).
  • Kolom TOTAL menghitung sendiri (rumus), warna dan bentuk tabel tidak berubah.
  • Kotak yang memang tidak ada datanya dibiarkan kosong - itu normal.

6. Kalau ada masalah

  • Memindai tanggal lama: NORMAL, file acuan besar (±1MB) butuh beberapa detik untuk dibaca.
  • Tanggal kosong (hanya ada tanggal): tanggal itu memang belum ada datanya di file acuan - pilih tanggal lain.
  • File gagal dibaca: pastikan file acuan valid (format .xlsx) dan tidak sedang dibuka di aplikasi lain.
  • Hasil tidak cocok: pastikan file acuan adalah Meal Charge yang benar.

7. Yang tidak boleh dilakukan

  • Jangan menutup file acuan selama proses generate berlangsung.
  • Jangan rubah nama atau pindah sheet di file acuan saat generate.
